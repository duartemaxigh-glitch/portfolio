# Maximiliano Duarte — Portfolio

Portfolio personal para presentar mi perfil como Backend Developer, con foco en Python y FastAPI.

## Proyectos destacados

- Sistema de gestión para Drugstore
- Sistema de gestión para servicio técnico de celulares
- La Esquina — sitio web comercial demostrativo

## Tecnologías del portfolio

- HTML
- CSS

Es un sitio estático y no requiere proceso de build.

## Ejecutar localmente

Abrir `index.html` directamente o servir esta carpeta mediante un servidor HTTP local.
